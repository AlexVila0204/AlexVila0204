## About me

I'm a full stack developer from Honduras. I build mobile apps, backends and the pieces that connect them, and I like owning a feature from the API to the release pipeline.

- Mobile: one Kotlin Multiplatform and Compose Multiplatform codebase that runs on iOS, Android and Sunmi POS terminals. I've also shipped React Native apps to TestFlight with fastlane.
- Backend: APIs in Go with gRPC, NestJS and Django, on PostgreSQL and MongoDB.
- Fintech: ISO 8583 messaging for POS terminals and electronic invoicing (DTE) for El Salvador's Ministry of Finance.
- AI: chat assistants on AWS Bedrock with tool calling and RAG.
- Freelance: Minecraft plugins (Paper, Spigot, Velocity) and server administration since 2023.

## Featured work

| Project | What it does | Stack |
|---|---|---|
| **Cross-platform invoicing app** | Issues and voids electronic invoices from iOS, Android and Sunmi terminals. Prints receipts, opens the cash drawer, shows the cart on a customer display and handles inventory with barcode scanning. | Kotlin Multiplatform · Compose · Ktor · CameraX · ML Kit |
| **Smart POS app** | Reads cards on Sunmi terminals and talks ISO 8583 to the acquirer host, with automatic reversals and batch close. | React Native · TypeScript · Sunmi SDK |
| **E-invoicing assistant** | Chat assistant that answers questions about invoices using RAG, plus a dashboard of business signals streamed in real time. | AWS Bedrock · NestJS · SSE |

> These projects are closed source. Screenshots and more detail are on [alexvila.me](https://alexvila.me).
